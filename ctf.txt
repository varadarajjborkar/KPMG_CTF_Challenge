ENTRY 12 - Corrupted Vision  (KPMG CTF)
================================================================================
FLAG: KPMG_CTF{S33K_AND_F1ND_M3}

Delivered: single file "challenge_file" (no extension), by email. No verify endpoint.
Hint: "We intercepted a file our tools can't classify. It looks like a simple profile
picture, but we know there's more. Expand your view to uncover the hidden payload."

SOLVE (three layers):
1. MAGIC-BYTE REPAIR. First 8 bytes were overwritten with the PNG signature
   (89 50 4E 47 0D 0A 1A 0A). File is really a JFIF JPEG. Restore bytes 0-7 to
   FF D8 FF E0 00 10 4A 46 -> valid JPEG. (This is why tools "can't classify" it.)
2. HEIGHT FALSIFICATION. SOF0 marker (file offset 0x9e) had its height field set to
   550 to crop off the lower portion. True content height = 1024. Patch the 2 bytes at
   0x9e+5 to 0x04 0x00 and decode (PIL, LOAD_TRUNCATED_IMAGES) -> the "expanded view"
   reveals a hidden 125-word text paragraph below the profile photo.
3. CLASSICAL CIPHER = MORSE via word lengths. Every one of the 125 words is exactly
   3, 5, or 7 letters. Mapping:  5 = dot (.),  7 = dash (-),  3 = letter separator.
   The 74 dot/dash symbols split into 26 Morse tokens, every one valid (letters,
   digits, and punctuation: ..--.-=_,  -.--.={ ,  -.--.-=} ).
   Decodes with zero leftover symbols to:  KPMG_CTF{S33K_AND_F1ND_M3}

Dead ends (recorded so they aren't repeated): treating 3/5/7 as base-3 digits in
groups of 5, Baconian (2-symbol), ternary->ASCII/base62, trifid. All fail because 3
is a SEPARATOR, not a value. User's steer "classical crypto, computing wasn't
involved" was the key tell.

Artifacts: corrupted_vision_fixed.jpg (header-fixed), corrupted_vision_expanded.png
(full 1024px, shows hidden paragraph).
